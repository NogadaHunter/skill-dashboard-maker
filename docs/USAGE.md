# 사용 프롬프트 모음

복사해서 `[ ]` 부분만 바꿔 쓰세요.

## 준비물

- (필수) Claude.ai: 설정 → 기능 → '클라우드에서 코드 실행' 켜기, 사용자 지정 → Skills에서 이 스킬 켜기
- (필수) 정리할 스킬이 한 개 이상 등록돼 있어야 해요
- (갱신할 때) 이전에 받은 `skill-dashboard.html`

## 기본: 처음 만들기

```text
스킬 대시보드 만들어줘
```

대시보드 제목은 "<이름>의 스킬 대시보드"로 만들어요. 이름을 모르면 한 번 물어봐요.

## 상황별

### 1. 이름을 정해서 만들기

```text
[이름] 이름으로 스킬 대시보드 만들어줘
```

### 2. 제목을 통째로 정하기

```text
'[마케팅팀 스킬 모음]'으로 스킬 대시보드 만들어줘
```

### 3. 이름 없이 만들기

```text
스킬 대시보드 만들어줘. 이름 없이 만들어줘.
```

제목이 '나의 스킬 대시보드'가 돼요.

### 4. 스킬을 바꾼 뒤 갱신하기

```text
(파일 첨부: skill-dashboard.html)
스킬 대시보드 갱신해줘
```

바뀐 스킬만 다시 정리하고, 대시보드 맨 위에 추가·수정·삭제 내역을 보여 줘요. 제목과 이름은 이전 대시보드에서 이어받아요.

### 5. 스킬 폴더를 직접 알려 주기 (Claude Code)

```text
스킬 대시보드 만들어줘. 스킬 폴더는 [C:\Users\내계정\.claude\skills]야.
```

Claude Code에서는 개인 스킬 폴더(`~/.claude/skills`)를 먼저 찾아요. 다른 곳에 있는 스킬을 정리하려면 이렇게 위치를 알려 주세요.

## 대시보드 쓰는 법

1. 검색창에 하고 싶은 일을 쓰거나 카테고리를 눌러요.
2. 스킬을 고르면 오른쪽에 기본 프롬프트와 상황별 프롬프트가 나와요.
3. **복사**를 눌러 Claude 대화창에 붙여 넣고 `[ ]` 부분만 바꿔요.

## 알아 두면 좋은 점

- 대시보드는 자동으로 바뀌지 않아요. 스킬을 추가·수정·삭제했으면 위 4번처럼 갱신을 요청하세요.
- 대시보드 파일은 인터넷 없이 열려요. 파일을 저장해 두거나, Claude.ai 아티팩트로 띄웠다면 사이드바에 고정해 두세요.
- 스킬이 40개가 넘으면 8~10개씩 나눠서 정리하고, 묶음마다 진행 상황을 알려 줘요.
- 대시보드에는 내가 정해 준 이름 말고는 개인·회사 정보나 내 PC의 폴더 경로가 들어가지 않아요.
