# example-lecture-planner

skill-dashboard-maker 예시를 보여 주려고 만든 가상 스킬이다.

## 입력
- 강의 주제, 교육 대상, 총 시간(예: 3시간, 2일 16시간)

## 단계
1. 학습 목표 3개를 정한다.
2. 차시별로 주제·활동·실습·시간을 나눈 커리큘럼 표를 만든다.
3. 차시마다 도입·전개·정리 흐름의 강의안을 쓴다.
4. 커리큘럼 표와 강의안을 DOCX 1개로 저장한다.

## 모드
- 반나절 특강
- 여러 날 과정
