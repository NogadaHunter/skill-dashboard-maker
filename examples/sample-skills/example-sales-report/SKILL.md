# example-sales-report

skill-dashboard-maker 예시를 보여 주려고 만든 가상 스킬이다.

## 입력
- 매출 데이터 XLSX 또는 CSV (날짜, 품목, 금액 열)

## 단계
1. 날짜·금액 열을 찾아 월별로 합친다.
2. 전월 대비 증감과 상위 품목 5개를 계산한다.
3. 월별 추이 차트를 넣은 요약 시트를 만든다.
4. 보고서 XLSX와 한 쪽 요약 PDF로 저장한다.

## 필요한 것
- 코드 실행(파일 생성) 기능
