# example-blog-writer

skill-dashboard-maker 예시를 보여 주려고 만든 가상 스킬이다.

## 입력
- 주제, 핵심 키워드 3~5개, (선택) 독자층·글 길이

## 단계
1. 키워드로 제목 후보 5개를 만든다.
2. 소제목 4~6개로 본문 구조를 잡는다.
3. 2,000자 안팎으로 본문을 쓰고, 마지막에 요약과 해시태그를 붙인다.
4. 마크다운(MD)으로 돌려준다.

## 모드
- 정보형 글
- 후기·경험형 글
