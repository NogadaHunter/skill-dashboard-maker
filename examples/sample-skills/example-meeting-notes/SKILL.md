# example-meeting-notes

skill-dashboard-maker 예시를 보여 주려고 만든 가상 스킬이다.

## 입력
- 회의 메모, 녹취록(TXT·DOCX), 채팅 기록

## 단계
1. 참석자·일시·안건을 찾는다. 없으면 [확인 필요]로 둔다.
2. 논의 내용을 안건별로 묶고, 결정사항과 보류 사항을 나눈다.
3. 담당자·기한이 있는 할 일을 표로 뽑는다.
4. 회의록 DOCX 1개로 저장한다.

## 모드
- 기본 회의록
- 보고용 한 쪽 요약
- 할 일 표만 뽑기
